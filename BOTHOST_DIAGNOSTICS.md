# Проверка Mini App на Bothost

После деплоя открой:

```text
https://<реальный-домен>/health
https://<реальный-домен>/api/miniapp/diagnostics
https://<реальный-домен>/api/miniapp/ping
```

Пришли полный JSON из `/api/miniapp/diagnostics` и последние 80 строк логов запуска.
Endpoint не возвращает токены и секреты. В нём видны только статус сервера, порт, URL, DNS-проверки Telegram/Supabase и состояние интеграций.

## Настройки Bothost

- Домен должен быть включён в панели.
- Внутренний порт панели должен совпадать с `PORT`.
- Для текущего Node-сервера используй `PORT=3000`.
- Сервер слушает `0.0.0.0`.
- Отключи HTTP Wrapper/автоматическую HTTP-обёртку: в проекте уже есть собственный сервер.
- После изменения переменных выполни повторный деплой.

Обрати внимание: переменные панели имеют приоритет над `deploy_config.json`. Если в логах появляется старый `WEBAPP_URL`, он всё ещё задан в переменных Bothost.
